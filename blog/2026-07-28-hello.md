# Hello, blog

This is the first post on the new blog section. I plan to use this space for short notes, paper updates, and thoughts on AI systems, causal inference, and sequential decision making.

To add a new post, create a `.md` file in `blog/` and run:

```
.venv/bin/python build_blog.py
.venv/bin/python jemdoc.py *.jemdoc
```
